No email, no password, no subscription. A 16-digit unlock code opens your account. Inside it you create rotatable API keys — those are what your code actually uses. We store only hashes.

HOW IT WORKS
  1. 01 Create your account. Save the 16-digit unlock code — shown once, it is not an API key.
  2. 02 Unlock the account and create an API key (ae_…) for X-API-Key. Create, reset or revoke keys anytime.
  3. 03 Start with 50 credits. Top up only when you need to, with a prepaid voucher. PayAsYouGo.
PAY AS YOU GO

No monthly subscription. Credits never reset on a calendar date. A failed request is never charged. You are in control of when — and whether — you pay.
