01 / THE PROBLEM

      
The data is public.
The access isn't.

      
Some of the most useful data on the web sits behind a paywall, a partner programme, or no API at all. We think that's a design flaw worth fixing — with infrastructure you own.

    

    

      

        01
        
¤

        
Paid by default

        
Official APIs are gated, metered, or reserved for partners. A hobby project gets a bill before it gets a single request.

        vendor lock-in
      

      

        02
        
⌗

        
Every shape is different

        
Three services, three auth flows, three response formats, three error codes. The integration work is the actual product.

        fragmentation
      

      

        03
        
◇

        
Someone else's switch

        
A hosted scraper can disappear, change pricing, or get taken down. Your application shouldn't have a single point of failure that isn't yours.

        no sovereignty

02 / CONNECTORS

      
Three services.
One contract.

      
Each connector is an independent HTTP service with the same routes, the same response shapes, the same logs and the same deployment story. Click one to see a real response.

    


    

      

        
        
        
      


      

        

          GET /v1/instagram/kametolol/posts?limit=2
          
        

        

        

          anon_grid · 200 · ~1.3 s · no session, no proxy
           key  string  number
        

      

    


    

      
ANONYMOUS BY DEFAULT
Instagram posts, LinkedIn jobs and TikTok profiles resolve with no account, no cookie and no proxy configured.

      
STRATEGY CHAINS
When an upstream endpoint is retired or throttled, independent sources take over. Selectors and doc_ids are configurable from .env.

      
OPTIONAL PROXIES
Bare user:pass@host:port credentials, rotation, startup liveness/country/latency probes, and a direct-vs-proxy comparison.

      
DATA POLICY
LinkedIn people profiles are opt-in and self-host only. The public surface serves jobs, companies and aggregate counts.

04 / SELF-HOST

      
Three commands.
No sign-up.

      
Node 22+ or Docker. No build step, no framework, no external service to register with.

    


    

      

        
        
        
      

      

      
    


    

      
PORTS
Each connector listens on its own port (3000 by default). Change PORT in .env to run several at once.

      
HOT RELOAD
Ctrl+R reloads the entire configuration in place. Ctrl+C stops cleanly. Disabled automatically when not in a TTY.

      
SECRETS
.env stays local and gitignored. Credentials are redacted in every log and API response. A 16-digit key can optionally gate your instance.
